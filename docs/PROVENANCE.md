# Provenance and portfolio preparation

The source is Ruijia Liu's PHYS20762 Computational Physics Project 3 notebook, titled *Neutron Transport and Scattering Through a Shielding Layer*. The original local notebook was preserved unchanged outside this repository. This public-facing copy uses a descriptive filename without the student identifier.

The source already contained the sampling demonstrations, homogeneous transport, thickness and attenuation study, Woodcock extension and random-forest experiment. Portfolio preparation did not originate those sections.

Subsequent AI-assisted preparation added the repository documentation, reproducible execution entry point, fixed NumPy seed, figure and table exports, automated consistency checks, and presentation edits. It incorporated a previously prepared thickness-holdout evaluation and simple baselines. The identical-layer comparison now combines standard errors of the means; the absorption histogram fit also excludes zero-scatter bins. Discussion of surrogate performance was qualified to reflect the holdout results.

The original simulation sample sizes, material constants and random-forest hyperparameters were retained. The repository does not establish sole authorship of every original code segment or replace course-specific attribution requirements. No third-party coursework brief, marking rubric or unrelated application documents are included. No blanket open-source licence is assigned by this preparation.
